# Third-party stuff

## VB-CABLE

VB-Audio Virtual Cable by Vincent Burel.  
https://vb-audio.com/Cable/

MicPilot talks to `CABLE Input` / `CABLE Output`. The driver is not bundled. You install it yourself.

## .NET / Windows

WASAPI and the rest of the Windows audio stack. Microsoft licenses apply.

## NAudio

MIT. Used for device listing and WASAPI capture/render.  
https://github.com/naudio/NAudio

## Simple Icons

Game / Discord / GitHub marks in the UI come from [Simple Icons](https://simpleicons.org) (CC0).  
FiveM is drawn green to match the current client icon.

MicPilot — NullEx17 icon pack

This pack is intentionally minimal and monochrome to match the NullEx17
black/white/gray identity.

Included:
- app/      Windows app icons + multi-resolution .ico files
- tray/     transparent system-tray icons
- overlay/  transparent mute/unmute overlay icons
- branding/ brand color/design rules

Important:
Use the ON/MUTED/IDLE assets according to the real microphone state.
Do not invent additional logo variants or add gradients/mascots.

The provided reference image in the conversation is the visual/product
direction for the complete MicPilot UI. The assets here are the actual
simple icon resources to integrate into the project.
